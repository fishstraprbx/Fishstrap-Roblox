# Fishstrap Roblox

**Fishstrap Roblox** extends Roblox bootstrapping with FastFlags, FPS unlocking, multi-instance launches, and Discord integrations (`fishstrap/Fishstrap`).

## What Shipped in v3.3.0
- **Discord Game Invites**: Enable `Allow Discord invites` under Integrations so friends can join public or web private servers from chat.
- **Desktop Game Shortcuts**: Paste any Roblox link in the Shortcuts tab to generate a direct icon shortcut.
- **BloxstrapRPC & Update Fixes**: Restored custom Discord Rich Presence after Roblox log renames (`#1510`) and fixed update-check retries.
